# 🍿 Netflix Database Design & Web App

A full-stack web application featuring a robust relational database schema and complex data analytics queries, implemented with ASP.NET Core MVC and PostgreSQL.

## 📌 Project Overview
This project simulates a streaming platform ecosystem. It covers both database design principles (normalization, constraints, relational integrity) and backend web development for user management, content exploration, and administrative controls.

## 🗄️ Database & SQL Highlights
- **Relational Schema:** Designed a 6-table normalized PostgreSQL database architecture with strict foreign key constraints and data validation rules.
- **Advanced Queries:** Authored 10+ complex SQL scripts utilizing multiple `JOIN` operations, aggregate functions, and subqueries for platform analytics.

## 🌐 Web Application Features
- **User Authentication:** Secure login and session handling.
- **Dynamic Content Listing:** Browse movies and shows filtered by categories and metadata.
- **Admin Management Panel:** Administrative interface for content and database management.

## 💻 Tech Stack
- **Backend & Web:** ASP.NET Core MVC, C#
- **Database:** PostgreSQL, DBeaver, Advanced SQL
- **Architecture:** MVC (Model-View-Controller) Pattern
